Installation
====================================

There are two different versions of the engine available for use - **exe** and **git**.

The **exe** version is a build of the latest **git** version available at the time it has been upload. New releases are shipped with some regularity, that may range from a a few weeks to a couple of months. This means certain bugs that have been fixed will linger until the next release. It has the advantage of being plug-and-play and that it can be installed on external devices.

Meanwhile, the **git** version constantly receives updates and those are quick and easy to fetch. It also allows the user to contribute to the engine  development. The only issue with it is that the installation process is significantly harder than the exe version. For Linux and Mac users, this is the only option available.

On simpler terms, the **exe** version is capable of building a whole game but is more appropriated to be used as a trial version of the engine and also as an alternative for those who need to work on multiple computers. If neither apply to you, we recommend installing the **git** version instead.

You can have both versions installed if you want or need to, but the **git** version will often offer more.
