Installation
====================================

There are two different versions of the engine available for use - **exe** and **git**.

The **exe** version is a build of the latest **git** version available on its upload, getting a new release with somewhat of a regular interval. This means it won't have certain features and bugfixes available for the git version.

Meanwhile, the **git** version constantly receives updates and those are quick and easy to fetch. It also allows the user to contribute to the engine  development. The only issue with it is that the installation process is significantly harder than the exe version. For Linux and Mac users, this is the only option available.

On simpler terms, the **exe** version is capable of building a whole game but is more appropriated to be used as a trial version of the engine. If you're set on making your own game, go for the **git** version instead.

You can have both versions installed if you want to, but the **git** version will always offer the same and more.
